# Design

The editor is a writing tool. Its source and preview occupy the viewport, with compact formatting and view controls above them. Desktop defaults to a two-column split; narrow screens default to editing with optional stacked split view.

The light palette uses warm paper (#fffefa), a soft surrounding surface (#faf9f6), charcoal text (#292b27), quiet borders (#e4e5dd), and a muted green focus/selection accent (#3d5838). A system dark palette follows the browser preference. System sans-serif serves controls and preview text; a monospace font serves source and code. Keyboard focus, text selection, disabled controls, storage errors, and empty preview states are explicit.
