# Markdown Web

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A minimal web Markdown editor that saves its contents in localStorage.

## Capabilities and Constraints

The user's requested repository is jacobzymet/markdown-web. Saving happens in the browser. No backend is required.

## Implementation Decisions

Static HTML, CSS, and JavaScript, with locally bundled Markdown parsing and sanitization. Live preview, responsive editing modes, and Markdown download support the core writing task.
